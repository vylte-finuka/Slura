MaratineKit tool's builder

Sélectionnez un frame représentant un écran d'app, puis générez ses sources Maratine (.marep) prêtes pour marai build.

Choisissez une image (PNG/JPG/WebP) : elle devient l'icône de lancement du dock, recadrée sur son contenu et centrée. Si vide, le nœud AppIcon du design est utilisé (sinon pas d'icône).

Double usage : (1) écrite dans Maraset.yaml (diamond_color) — ShiLauncher colore automatiquement le losange de CETTE app dans le dock et sa barre de titre, aucune modification de ShiLauncher requise. (2) Si le design contient un nœud [diamond] (ex. « Icône [diamond] »), il est rendu en losange verre dans CETTE MÊME couleur à l'intérieur de l'app (le fill Figma du nœud est ignoré ; ses enfants, ex. une icône, sont dessinés par-dessus, non pivotés).
