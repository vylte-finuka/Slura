ShiUI Kit tool

Transforme une/des forme(s) DÉJÀ DESSINÉE(S) par vous en ruban de soie fluide (signature ShiUI, façon fond d'écran Windows 11 — highlights satinés inclus) OU en anneau rotatif mat façon papier plié. Votre couleur de base reste celle de votre forme, jamais remplacée par le plugin.

Sélection

Aucune forme sélectionnée.

Sélectionnez 1 forme existante (vecteur, rectangle, ellipse...) pour une silhouette statique, ou 2+ formes (dans l'ordre gauche → droite) pour une animation — jamais un frame.

Mode

Ruban de soie
Anneau (papier mat)

Géométrie

Contour toujours un cercle parfait (pas de bord ondulé) — l'effet "cordon torsadé" (pâtes torsadées) se voit uniquement via l'ombrage ("Organicité" = intensité de la torsion), jamais via la silhouette.

Ombre

Anneau : reste strictement mat, aucun reflet clair (variations sombres uniquement). Ruban de soie : highlights satinés inclus dans le dégradé du corps (voir "Mode" ci-dessus).

Animation (Smart Animate)

Le nombre de keyframes = le nombre de formes sélectionnées (voir "Sélection" ci-dessus) — pas un réglage séparé. Câblage du prototype possible seulement si chaque forme est posée dans son propre frame de premier niveau (limite de l'API Figma). Avec 1 SEULE forme sélectionnée, le résultat est une silhouette statique (aucune rotation visible n'est possible sans keyframes) — pour un anneau qui tourne vraiment, sélectionnez 2 formes ou plus.

Même topologie de points sur toutes les formes → morph liquide réel, pas un simple fondu. Le câblage du prototype est best-effort : vérifiez en mode Présentation, reliez à la main dans l'onglet Prototype si besoin.
